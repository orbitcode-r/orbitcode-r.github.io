# orbitcode-r.github.io

GitHub Pages site for **Privacy Blur for WhatsApp** uninstall.

## Uninstall Feedback Page

`/uninstall` — shown to users when they uninstall **Privacy Blur for WhatsApp**.

- Supports 19 languages with automatic locale detection via `?lang=` URL param
- RTL support for Arabic and Hebrew
- Feedback is collected and stored privately
- No tracking, no analytics, no external dependencies

## Structure

```
uninstall/
  index.html        # Markup
  style.css         # Styles (dark/light mode)
  form.js           # Form logic and submission
  logo.png          # Extension logo
  i18n/             # One JSON file per locale
```
